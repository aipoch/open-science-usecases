# Gold vs Bitcoin 28 Days Changed the Winner

## Archived study

Values equal-dollar GLD and IBIT purchases using a supplied price table and compares several entry dates. The archived tables and charts illustrate how the winner changes with the chosen historical start.

## Interpretation and limits

The analysis concerns the supplied checkpoints and ETF proxies. Entry-date sensitivity is not a prediction of future returns or a recommendation to buy either asset.
